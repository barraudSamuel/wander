# Review Findings

This directory stores actionable issues found during review but not resolved in the current change.

Use `_template.md` and name files `NNN-status-pN-short-description.md`, for example `001-ready-p1-protect-location-write.md`. Priorities are `P1` (must fix before shipping), `P2` (important), and `P3` (optional improvement). Valid statuses are `pending`, `ready`, `in-progress`, `blocked`, and `done`.

Keep evidence and acceptance criteria concrete. Remove or archive completed findings after their reusable lesson has been captured in `docs/solutions/` when appropriate.
